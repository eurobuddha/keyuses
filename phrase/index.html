Minima · Seed Address Audit

KeyUses Phrase

Type a Minima seed phrase (24/12 BIP39 words, or an “anyphrase”) and this dapp derives that seed's default addresses right here on your device — in both key schemes: the classic 64 keys every node creates today, and the 32 different keys a -blockaskeyuses node (minimaCore 1.1.2.31+) creates from the same phrase — then checks each one against the on-chain signature history and the canonical key-reuse list. The phrase is never sent anywhere; only the resulting public addresses are looked up.

What this tells you

Minima keys are stateful: each key is a tree of one-time signatures (classic: 64 keys of 262,144 leaves; -blockaskeyuses nodes: 32 different keys of 268,435,456 leaves, derived from the same seed), and a leaf is only secure if it signs once. Re-using a leaf leaks the key and makes forgery progressively easier.

This dapp reconstructs the addresses a seed produces under both schemes and reports, per address: whether it appears in the witness-confirmed reuse list, how many times it has signed on-chain, and the balance as the audit node sees it (it can't see coins it doesn't track, so "unknown" there says nothing about your real balance). From the busiest key it computes the safe keyuses value to set when you next restore this seed, so a re-sync never re-issues a leaf the chain has already seen.

Privacy: the phrase and derived seed stay on your device — only the resulting public Mx… addresses are sent to the eurobuddha archive for the lookup, and addresses cannot move funds. For a fully offline derivation, disconnect after the addresses appear.
