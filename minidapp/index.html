Minima · Key Security Audit

KeyUses

Minima signatures are stateful: each of your 64 keys can sign safely only by moving to a fresh leaf each time. If a seed re-sync set keyuses too low, your node can re-use a leaf it already spent on-chain — which is forgeable. This tool reads your keys, checks how many times each was really used on an archive, and tells you if you're at risk.

Privacy: in eurobuddha archive mode your 64 public keys are sent to eurobuddha.com to be looked up against the archive. Public keys cannot move funds, but they do reveal your addresses to that server. For full privacy, run your own archive and use My own archive mode.
